# Календарь ФСП

Публичная страница календаря показывает **наши события ФСП** (то, что не соревнование: лекции, сборы, вебинары, собрания) и **действительные соревнования** (все статусы, кроме черновика и архива). Контракт — [001_api_map.md](001_api_map.md), раздел «Календарь».

- События ФСП ведёт федерация: `/admin/calendar/events` (черновик → опубликовано → архив).
- Соревнования ведутся своими эндпоинтами ([007](007_tz_contests.md)) и попадают в календарь автоматически, когда становятся действительными.
- В ленте у элемента есть `kind` (`event` / `contest`); для соревнования — `contest_id` и значок верификации `is_verified`.
- Календарь Минспорта / Минцифры удалён (был только для теста): нет внешней загрузки, снимка данных, таблицы источников и Redis-блокировки.

## Что поменять во фронте
- В типах календаря: убрать `source`, `source_url`, `sources`; добавить `kind`, `contest_id`, `status_title`, `is_verified`; `id` — строка.
- Фильтр «источник» заменить на `kind=event|contest`.
- Клик по соревнованию ведёт на карточку соревнования (`/contests/{contest_id}`), по событию — на карточку события.
- Админка событий (`/admin/calendar/events`) — без изменений, кроме отсутствия `source` / `source_url` в ответах.
