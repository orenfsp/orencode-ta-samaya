# 013. Судьи, судейские категории и спортивные разряды

Категория судьи и разряд спортсмена устроены одинаково: подача с документом → решение федерации → срок действия → напоминание → повышение новой заявкой. Поэтому это один механизм «квалификаций» двух видов.

## Сущности

**`qualifications`** — заявка и присвоение.
- `kind`: `judge_category` или `rank`. Ссылка на справочник `dictionary_judge_categories` или `dictionary_rank_types`, ровно одна (`ck_qualifications_item`).
- `user_id` — чья квалификация. `submitted_by` — кто подал: сам человек или тренер.
- `document_file_id` — документ-основание (PDF/DOCX, обязателен). `basis` — текст основания.
- `status`: `pending` → `approved` | `rejected`. Свою `pending` можно отозвать (`withdrawn`). Когда одобряется новая ступень, прежняя одобренная становится `superseded`.
- `valid_from`, `valid_until`. `valid_until = null` у одобренной — бессрочно.
- На человека и вид — не больше одной `pending` и одной `approved` (частичные уникальные индексы).

**`judge_assignments`** — судейская коллегия: соревнование, судья, должность из `judge_positions`. Один судья в коллегии один раз.

**`deadline_notices`** — уже отправленные напоминания: `(qualification_id, threshold_days)` уникально.

## Правила

**Кто подаёт:**
- категорию — сам судья с подтверждённой ролью;
- разряд — сам спортсмен или тренер за спортсмена из своих заявок на соревнования (участники заявок, созданных тренером).

**Что можно подать:** только ступень выше действующей. В справочнике выше стоит более высокая ступень, поэтому сравнение идёт по `id`. Если действующая истекла, подать можно любую. Разряд с `min_age` проверяется по возрасту на сегодня.

**Срок при одобрении** (день решения по Оренбургу):
- категория — `+ validity_months`;
- разряд — `+ validity_months`, звание с `is_lifetime` — бессрочно;
- юношеский разряд — не дольше дня, когда спортсмену исполнится `valid_until_age` лет.

**Коллегия:**
- назначает организатор своего соревнования или федерация;
- соревнование не завершено, не в архиве и не отменено;
- у судьи категория действует на `starts_on` соревнования. Учитываются и `superseded`, если на эту дату она ещё действовала. Иначе 409 `category_not_valid`.

**Напоминания.** `DeadlineWatcher` работает в lifespan рядом с `OutboxWorker`, раз в `FSP_DEADLINE_INTERVAL_SECONDS` (по умолчанию час).
- Пороги — `FSP_DEADLINE_THRESHOLDS_DAYS` (30, 7, 1) и 0 («истекло»).
- Для одобренной квалификации берётся наименьший пройденный порог. Запись в `deadline_notices` делается через `INSERT … ON CONFLICT DO NOTHING`, уведомление уходит, только если запись новая. Поэтому повторов нет даже при нескольких экземплярах.

## API

| Метод | Путь | Кто |
|---|---|---|
| GET | `/me/qualifications` | все: `items` — свои, `submitted` — поданные за других |
| GET | `/me/athletes` | тренер: спортсмены из его заявок |
| POST | `/qualifications` `{kind, user_id?, item_id, document_file_id, basis?}` | судья, спортсмен, тренер |
| POST | `/qualifications/{id}/withdraw` | автор или владелец |
| GET | `/admin/qualifications?kind&status` | федерация; `status` по умолчанию `pending` |
| GET | `/admin/qualifications/{id}/preview` | федерация: срок, если одобрить сегодня |
| POST | `/admin/qualifications/{id}/approve` | федерация |
| POST | `/admin/qualifications/{id}/reject` `{reason}` | федерация |
| GET | `/contests/{id}/judges` | все |
| GET | `/contests/{id}/judges/candidates?q` | организатор, федерация |
| POST | `/contests/{id}/judges` `{judge_id, position_id}` | организатор, федерация |
| PATCH | `/contests/{id}/judges/{assignment_id}` `{position_id}` | организатор, федерация |
| DELETE | `/contests/{id}/judges/{assignment_id}` | организатор, федерация |
| GET | `/me/judge-assignments` | судья |

**Ошибки:**
- 409 `already_pending`, `not_higher`, `category_not_valid`, `already_assigned`;
- 403 — не тот, кто может подать или назначить.

Документ скачивается по `/files/{id}`: доступен загрузившему и федерации.

## Уведомления

Новая группа настроек — «Разряды и категории» (`qualifications`).

| Тип | Кому | Группа | Письмо |
|---|---|---|---|
| `qualification.requested` | федерации | Модерация | нет |
| `qualification.approved` / `rejected` | владельцу и подавшему тренеру | Разряды и категории | да |
| `qualification.expiring` / `expired` | владельцу | Разряды и категории | да |
| `judge.assigned` / `judge.removed` | судье | Соревнования | да |

Аудит: `qualification.submit|withdraw|approve|reject`, `judge.assign|update|remove`.

## Экраны

- **Судья** — «Моя категория» (`/cabinet/judge/category`): текущая, срок, история, «Подать заявку» / «Повысить категорию». «Мои назначения» (`/cabinet/judge/assignments`).
- **Спортсмен** — «Мой разряд» (`/cabinet/athlete/rank`).
- **Тренер** — «Разряды спортсменов» (`/cabinet/coach/ranks`): поданные им заявки и подача за спортсмена.
- **Федерация** — «Разряды и категории» (`/cabinet/federation/qualifications`): вкладки «Судейские категории» / «Разряды», фильтр статуса. «Присвоить» показывает рассчитанный срок; «Отказать» — с причиной.
- **Организатор и федерация** — кнопка «Судьи» на карточке соревнования открывает окно коллегии.
- Срок везде показывает `ValidityTag`:
  - «Действует до…»;
  - «Истекает через N дн.» (красная, за 30 дней);
  - «Истекла…»;
  - «Бессрочно».
