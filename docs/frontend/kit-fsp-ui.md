# UI/UX-кит: Федерация спортивного программирования России (ФСП)

Документ для генератора интерфейсов. Задача: по этому описанию делать страницы и компоненты в стиле ФСП, не придумывая лишнего.

## 0. Как читать документ

Каждый пункт помечен источником, чтобы не путать факт и предложение:

- **[БРЕНДБУК]** прямо указано в официальном брендбуке (fsp-russia.ru/press/brandbook/)
- **[САЙТ]** видно на текущем сайте fsp-russia.ru (структура, состав, тексты)
- **[ПРЕДЛОЖЕНИЕ]** не из источника, а рекомендация для генерации. Менять можно, если заказчик скажет иначе

Чего источники НЕ дают: css (радиусы, отступы, размеры шрифта, тени, брейкпоинты). Все числа ниже, помеченные [ПРЕДЛОЖЕНИЕ], выбраны для консистентности и должны быть сверены с макетами или devtools сайта.

Источники: брендбук, главная, /calendar/, /press/news/, /about/nationalteam/, /about/member/. Страница /region/ недоступна для чтения ботом, по ней данные только с главной.

## 1. Бренд в одной строке

Серьёзная спортивная федерация + IT. Характер: технологичный, чёткий, соревновательный, без детскости и без «корпоративной вялости». Моноширинный шрифт задаёт «кодовый» тон, синий + красный задают спортивную энергию.

Организация: Общероссийская спортивная федерация, 89 региональных представительств, дисциплины: продуктовое, алгоритмическое программирование, программирование систем ИБ, робототехники, БАС.

## 2. Дизайн-токены

### 2.1 Цвета [БРЕНДБУК]

| токен | hex | роль (роль — [ПРЕДЛОЖЕНИЕ]) |
|---|---|---|
| `--fsp-blue` | `#402FFF` | основной акцент, кнопки, ссылки, активные состояния |
| `--fsp-red` | `#EC1D35` | вторичный акцент, выделение, важные метки |
| `--fsp-light` | `#EDEDED` | светлый фон, подложки карточек |
| `--fsp-gray` | `#C8C9CA` | границы, неактивное, второстепенный текст на тёмном |
| `--fsp-ink` | `#1B1C21` | основной текст и тёмный фон |

Белый `#FFFFFF` в брендбуке явно не задан, но нужен для текста на синем и как базовый фон. Использовать как нейтральный.

### 2.2 Контраст (посчитано по WCAG, это важно для генерации)

- белый на `#402FFF`: ~6.8:1, подходит для любого текста
- `#402FFF` на `#EDEDED` / белом: ~5.8:1+ и выше, подходит для текста и ссылок
- `#402FFF` на `#1B1C21`: ~2.5:1, **не использовать как цвет текста на тёмном**. На тёмном синий только как заливка с белым текстом
- белый на `#EC1D35`: ~4.4:1, ок только для крупного/жирного текста (от 18px bold) и кнопок; мелкий текст на красной заливке не делать
- `#EC1D35` на `#1B1C21`: ~3.9:1, только крупные элементы и иконки, не мелкий текст
- `#C8C9CA` на `#1B1C21`: ~10:1, подходит для второстепенного текста на тёмном
- `#1B1C21` на `#EDEDED` / белом: высокий, основной текст

### 2.3 Тема [ПРЕДЛОЖЕНИЕ]

Тема текущего сайта не подтверждена. Рекомендация: светлая база (белый / `#EDEDED`), тёмные секции (`#1B1C21`) для hero, футера и акцентных блоков со статистикой. Красный использовать дозированно: не больше одного красного элемента на экран.

### 2.4 Типографика

- Единственный шрифт: **JetBrains Mono** [БРЕНДБУК]. Лицензия SIL OFL 1.1, свободно в коммерции, упоминание не обязательно
- Подключение [ПРЕДЛОЖЕНИЕ]: Google Fonts или self-host, веса 400, 500, 700, начертания latin + cyrillic (в JetBrains Mono кириллица есть)
- Фолбэк: `ui-monospace, "SFMono-Regular", Menlo, Consolas, monospace`
- Так как шрифт моноширинный, ширина текста больше обычной: заголовки короче, межстрочный интервал плотнее

Шкала [ПРЕДЛОЖЕНИЕ] (desktop / mobile):

| роль | размер | вес | line-height |
|---|---|---|---|
| H1 | 44 / 28 | 700 | 1.15 |
| H2 | 32 / 22 | 700 | 1.2 |
| H3 | 22 / 18 | 700 | 1.25 |
| body | 16 / 15 | 400 | 1.5 |
| small / метки | 13 / 12 | 500 | 1.4 |
| числа-счётчики | 64 / 40 | 700 | 1 |

Не использовать letter-spacing > 0.02em, заглавные только для коротких меток.

### 2.5 Отступы и сетка [ПРЕДЛОЖЕНИЕ]

- Шаг 4px: 4, 8, 12, 16, 24, 32, 48, 64, 96
- Контейнер макс. 1200px, боковые поля 16px (mobile) / 32px (desktop)
- Сетка 12 колонок desktop, 4 колонки mobile, gap 24 / 16
- Брейкпоинты: 640, 1024, 1280
- Радиусы: 8px (карточки, поля), 999px (бейджи); кнопки 8px. Тени минимальные, лучше границы 1px `#C8C9CA`

## 3. Графические элементы [БРЕНДБУК]

Три фирменных элемента, использовать как декор в hero, пустых состояниях и разделителях:

1. **Голова** — силуэт потенциального участника чемпионатов
2. **Карта России** — обозначает регионы, где есть или будут представительства
3. **Линии** — соединяют региональные представительства (сеть)

Правила:
- Логотип и графику брать только из официальных файлов (брендбук скачивается: fsp-russia.ru/files/брендбук.rar, логотипы: /press/logotip/). **Не перерисовывать и не воссоздавать лого кодом**
- Лого есть в вариациях под светлый и тёмный фон (в т.ч. белые версии). Фон выбирать по контрасту
- Цвета лого: `#402FFF`, `#EC1D35`, `#EDEDED`, на тёмном ещё `#C8C9CA`, `#1B1C21`
- Линии-связи можно использовать как фон секции «Регионы» (точки + соединения), цвета только из палитры

## 5. Компоненты (точечно)

Для каждого: назначение, состав, состояния, правила. Ниже состав [САЙТ], оформление [ПРЕДЛОЖЕНИЕ].

### 5.1 Header
- Состав: лого слева, меню с выпадашками, справа соцсети, «Войти», «Регистрация», переключатель RU/EN, поиск
- Mobile: отдельный вариант лого (`logo_mobile`), бургер; внутри меню в 2 уровня + блок контактов (email, телефон, адрес) + соцсети
- Состояния пунктов: default / hover (синий) / active (синий + подчёркивание) / focus-visible (outline 2px синий)
- Фон светлый, sticky допустим, высота ~64–72px

### 5.2 Кнопки
- Primary: заливка `#402FFF`, текст белый, 8px, padding 12×20, hover темнее на ~8%, focus-ring 2px
- Secondary: обводка 1px `#402FFF`, текст синий, прозрачный фон
- Danger/акцент (редко): заливка `#EC1D35`, только крупный жирный текст
- Text link: синий, подчёркивание при hover
- Disabled: `#C8C9CA` фон, текст `#1B1C21` 50%
- Кнопка «Подробнее» в карточках: secondary или text link со стрелкой
- Кнопка «Скачать документ»: secondary + иконка загрузки, подпись обязательна («физ.лицо» / «юр.лицо» там, где два варианта)

### 5.3 Карточка новости
- Состав: обложка (соотношение 16:9), дата, заголовок (до 3 строк), «Подробнее»
- Вариант «лента на странице новостей»: слева крупная дата в формате «13 / октября», справа заголовок + полная дата «13 октября 2026 г.» + обложка
- Hover: лёгкий подъём/обводка синим, вся карточка кликабельна
- Пагинация: кнопка «Больше событий» (load more), не бесконечный скролл

### 5.4 Строка события (на главной)
- Состав: название, дата («25 июня»), формат (Оффлайн / Онлайн), место («г. Санкт-Петербург», «по месту нахождения участников»)
- Одна строка = одна ссылка, разделитель 1px `#C8C9CA`

### 5.5 Календарь
- Шапка: стрелки «‹ ›» + «Октябрь 2026» (переключение месяцев через параметры month и year)
- Фильтры: «Любой город» (список городов + «определяется», «по всей России», «по месту нахождения участников»), «Любой тип» (Онлайн / Оффлайн)
- Сетка: Вс–Сб (Пн–Вс для RU-привычки уточнить у заказчика, на сайте порядок Вс..Сб в подписи, в короткой подписи Вс Пн Вт... Сб), дни соседних месяцев приглушены
- День с событием: подсветка, внутри карточка (см. 5.6)
- Mobile: сетку заменить на вертикальный список событий, сгруппированный по датам

### 5.6 Карточка события
Поля (порядок): название, дата `ДД.ММ.ГГГГ`, формат (бейдж), место, **Дисциплина**, **Участники** (возрастная метка), «Подробнее».
- Название выводить один раз (на сайте оно дублируется, это баг)
- Возрастные метки: `16+`, `до 18`, `14-18`, `16+ и 14-18` — в виде бейджей

### 5.7 Бейджи
- Формат: «Онлайн» (синий контур), «Оффлайн» (тёмный контур)
- Возраст: нейтральная серая подложка `#EDEDED`
- Дисциплина: цветная точка/иконка + текст
- Радиус 999px, 12–13px, вес 500

### 5.8 Карточка дисциплины
- Состав: иконка (в моно-стиле), заголовок H3, описание 1–2 строки
- 5 штук: Продуктовое программирование (хакатон), Алгоритмическое, Системы информационной безопасности, Робототехника, БАС
- Desktop: 5 в ряд или 3+2, mobile: 1 колонка / горизонтальный скролл

### 5.9 Статистика / счётчик
- Крупное число + подпись: «89 — действующих региональных представительств ФСП в России»
- Тёмная секция, число белым, акцент красным/синим точкой или линией
- Рядом карта России с точками регионов и линиями-связями

### 5.10 Таймлайн
- Дата крупно (моно, `19 октября 2021`), под ней текст события
- Вертикальная линия, узлы синие, последний узел можно красный
- События: основание (19.10.2021), признание видом спорта (12.04.2022), меморандум на ПМЭФ (16.06.2022), статус общероссийской федерации (17.02.2023), реестр СОНКО (02.08.2023)

### 5.11 Список регионов
- Состав элемента: метка «Федерация», название региона, ссылка «Контакты представительств»
- 89 элементов: нужны поиск по названию и группировка по федеральным округам (на сайте этого нет, [ПРЕДЛОЖЕНИЕ])
- Адреса вида `/region/regions/<slug>/`

### 5.12 Карточка человека (сборная)
- Состав: аватар (на сайте только иконка-заглушка), ФИО, округ и город
- Группировка: **Основной / Резервный состав** × **дисциплина** × **пол** (Женщины / Мужчины)
- Фото участников нужны, иначе блок «пустой»; заглушка — инициалы на синем круге
- Пустые группы (например, женский состав без участников) не выводить или писать «Состав формируется»

### 5.13 Степпер «Как стать членом»
- Нумерация [1]…[7] крупно моно-шрифтом, у шага: текст и 0–2 кнопки скачивания
- Шаги: ознакомиться с Уставом и правилами приёма → заявление → анкета → согласие на ПДн → копия паспорта → две фотографии 3×4 → вступительный взнос 10 000 ₽ (квитанция)
- В конце блок «куда отправлять» (email + почтовый адрес) выделить подложкой `#EDEDED`

### 5.14 Лента «ФСП в СМИ»
- Строка: лого издания, название, дата, заголовок (внешняя ссылка, открывать в новой вкладке, пометить иконкой «наружу»)
- Лента длинная, показывать 6, дальше «Показать ещё»

### 5.15 Партнёры
- Ряд логотипов (серые/монохромные, в цвет при hover), бегущая строка допустима, но с кнопкой паузы и `prefers-reduced-motion`
- Логотипы: Минспорт России, Столото, Mail.ru (VK), Советский спорт и др. Брать только официальные файлы

### 5.16 FAQ-аккордеон
- Вопрос = кнопка, раскрытие по клику, одновременно открыт один пункт, стрелка поворачивается
- Минимум два вопроса сейчас: про разряды и про региональное отделение

### 5.17 Footer
- Колонки: лого + © ; Контакты (email, телефон, адрес); Пресс-служба (email + телефон); Соцсети (vk, tg с qr); ссылки (Политика конфиденциальности, Условия соглашения), «Наверх», строка «Федерация спортивного программирования России ©<текущий год>»
- Фон `#1B1C21`, текст `#EDEDED`/`#C8C9CA`, ссылки белые, hover красный

### 5.18 Cookie-баннер
- Текст «Используем cookies для улучшения работы сайта» + ссылка на правила + кнопка «ОК». Фикс к низу, не перекрывает контент на mobile

### 5.19 Формы (регистрация, поиск, обратная связь) [ПРЕДЛОЖЕНИЕ]
- Поле: подпись сверху, высота 44px, обводка 1px `#C8C9CA`, focus 2px синий, ошибка красная обводка + текст ошибки под полем (не только цветом)
- Согласие на обработку ПДн чекбоксом со ссылкой на положение

## 6. UX-паттерны

- Главные пользовательские сценарии: найти ближайшие соревнования, зарегистрироваться на событие, найти свой региональный офис, вступить в федерацию, прочитать новости, скачать документы
- Календарь и регионы — ключевые страницы, им нужны фильтры и поиск
- Любой документ для скачивания: иконка + название + тип + размер файла (.pdf/.docx)
- У каждой страницы хлебные крошки (на сайте их нет)
- Внешние ссылки открывать в новой вкладке с пометкой
- Пустые, загрузочные и ошибочные состояния для списков (скелетоны, «Ничего не найдено»)
- Язык: RU основной, EN вторая версия; все строки интерфейса выносить в словарь

## 7. Тон текста

- Деловой, но живой, без канцелярита; факты и цифры вперёд
- Названия дисциплин и мероприятий писать как на сайте, не сокращать
- Формат даты: `13 октября 2026` в тексте, `09.10.2026` в карточках
- «Оффлайн» через два ф (как на сайте), «Онлайн»
- Валюта: `10 000 ₽` с неразрывным пробелом

## 8. Доступность

- Контраст по п. 2.2; не использовать синий текст на тёмном
- Не блокировать масштаб: **не** ставить `user-scalable=no` (на текущем сайте это ошибка)
- Видимый focus на всём интерактивном, навигация с клавиатуры, aria для меню, аккордеона, календаря
- Альтернативный текст у обложек и логотипов, `lang="ru"`
- Анимации уважают `prefers-reduced-motion`
- Цвет не единственный носитель смысла (онлайн/оффлайн, ошибки)

## 9. Известные проблемы текущего сайта (исправлять при генерации)

- «Войти», «Регистрация», «Условия соглашения», «Статистика» — ссылки без назначения
- `user-scalable=no` в viewport
- Два домена в контактах: info@fsp-russia.ru и info@fsp-russia.com — унифицировать
- Копирайт «©2025» при текущем 2026 — подставлять год динамически
- Дублирование названия события в карточке календаря
- В «Сборной России» нет фото, одинаковая иконка у всех
- Нет хлебных крошек, нет поиска по регионам

## 10. Запреты для генератора

- Не рисовать лого, голову и карту России кодом «по памяти», использовать только официальные файлы
- Не использовать другие шрифты и палитры
- Не добавлять сторонние бренды и фото без прав
- Не выдумывать данные: цифры (89 регионов, 10 000 ₽, даты) брать только из этого документа или от заказчика
- Не писать красный мелким текстом и синий текстом на тёмном фоне
