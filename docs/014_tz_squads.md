# 014. Сборные

Сборная Оренбургской области по дисциплине и группе, возрастной или академической. Состав — верх рейтинга этой группы на день утверждения. Сборная действует, пока её не заменит новый приказ или федерация её не расформирует.

## Сущности

**`squads`** — действующая сборная.
- `discipline_id`, ровно одно из `age_group_id` / `academic_group_id` (`ck_squads_group`).
- На дисциплину и группу — не больше одной сборной (частичные уникальные индексы `uq_squads_age`, `uq_squads_academic`).
- `main_size` от 1, `reserve_size` от 0 — сколько задано приказом.
- `order_number`, `order_date`, `order_file_id` — приказ, PDF, публичный файл.
- `approved_by`, `approved_at`.

**`squad_members`** — снимок состава: `position`, `is_reserve`, `points` на момент утверждения.

Истории нет. Новый приказ удаляет прежнюю сборную, её состав и файл приказа (из базы и из хранилища). След остаётся только в журнале действий.

## Правила

**Кто:** утверждает, обновляет и расформировывает только федерация.

**Состав.** Кандидаты — строки рейтинга группы за 365 дней по всей области: только те, у кого есть результат в верифицированном соревновании дисциплины. Порядок:
1. баллы рейтинга;
2. дата последнего 1-го места — свежее выше, без побед ниже всех с победами;
3. среднее занятое место — меньше выше, соревнования без места не считаются;
4. ФИО.

Первые `main_size` — основной состав, следующие `reserve_size` — резерв. Людей меньше — сначала заполняется основной состав, резерв получает остаток. В рейтинге никого — 409 `no_candidates`.

Состав считает сервер в момент утверждения, от клиента список людей не принимается. Править утверждённый состав нельзя: эндпоинтов изменения нет, только новый приказ.

**Приказ:** номер обязателен, дата не позже сегодняшней по Оренбургу, файл — PDF, загруженный этим же сотрудником и не прикреплённый к другой сборной. При утверждении файл становится публичным.

**Уведомления:** после каждого утверждения или обновления — всем членам нового состава, тип `squad.included`, письмом и в кабинете: «Поздравляем! Вы вошли в сборную …» или «… в резерв сборной …». Выбывшим ничего не приходит.

**Аудит:** `squad.approve`, `squad.replace` (с номером прежнего приказа), `squad.dissolve`. В `payload` — `id`, название, приказ и состав.

## Экраны

- **Страница «Сборные»** (`/squads`, в шапке сайта рядом с «Рейтингом»): дисциплина и «По возрасту / По учёбе», действующие сборные карточками — группа, приказ ссылкой на PDF, основной состав и резерв рядом. У федерации в карточке меню «⋯»: «Новый приказ», «Расформировать»; ниже — «Без сборной»: группы с рейтингом и кнопка «Утвердить». Ссылка на сборную — `/squads?discipline_id=&kind=&group_id=`.
- **Окно утверждения:** размеры составов, предпросмотр кандидатов с предупреждением о нехватке людей, номер и дата приказа, загрузка PDF. Если сборная есть — предупреждение о замене.
- **Таблица рейтинга:** пометка «сборная» у членов действующей сборной.
- **Страница человека:** метки «Участник сборной Оренбургской области · Дисциплина · Группа» со ссылкой на подвкладку. Резерв отдельно не помечается.

## Демо

Две сборные по самым заполненным возрастным рейтингам: 3 + 2 и 2 + 1.
