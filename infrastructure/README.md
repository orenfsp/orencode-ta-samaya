# Модели

ORM-модели SQLAlchemy: одна таблица на файл, файлы разложены по папкам групп. В корне — общая база `base.py` и перечисления для колонок `enums.py`. Схема создаётся из этих моделей при каждом старте (`manage/bootstrap.py`), миграций нет. Демо-данные — `manage/seed/seed.sql`.

Папки и файлы внутри них в проводнике VS Code идут в том же порядке, что в таблице (`.vscode/settings.json`). Оформление моделей одинаковое: поля в одну строку, каждая связь отдельным многострочным блоком; подробно — [backend/RULES.md](../backend/RULES.md).

| Группа | Модель | Что хранит |
|---|---|---|
| **Основа** (корень) | `base.py` | База ORM и общие поля справочников: название, описание, архив |
| | `enums.py` | Перечисления для колонок: статусы, роли, виды |
| **Аккаунт** `account/` | `user.py` | Человек: ФИО, дата рождения, группа, муниципалитет, Codeforces, видимость страницы, аватар |
| | `user_role.py` | Роль человека и решение федерации по ней |
| | `wall_post.py` | Пост в ленте человека к соревнованию |
| | `wall_post_photo.py` | Фото поста |
| | `guardian_consent.py` | Согласие законного представителя несовершеннолетнего |
| | `login_device.py` | Устройство входа: для уведомления «вход с нового устройства» |
| **Общие службы** `services/` | `audit_log.py` | Журнал действий: кто, что, когда, изменения |
| | `file.py` | Загруженный файл в хранилище: ключ, тип, размер, публичность |
| **Справочники** `dictionaries/` | `dictionary_discipline.py` | Дисциплины спортивного программирования |
| | `dictionary_municipality.py` | Муниципалитеты области |
| | `dictionary_organization_type.py` | Типы организаций |
| | `dictionary_academic_group.py` | Академические группы: классы, студенты |
| | `dictionary_age_group.py` | Возрастные группы с границами |
| | `dictionary_contest_type.py` | Типы соревнований: чемпионат, кубок… |
| | `dictionary_contest_level.py` | Уровни соревнований: региональное… |
| | `dictionary_contest_format.py` | Форматы: очно, онлайн, смешанный |
| | `dictionary_rank_type.py` | Разряды и звания: сроки, мин. возраст |
| | `dictionary_judge_category.py` | Судейские категории и их срок |
| | `dictionary_judge_position.py` | Должности в судейской коллегии |
| **Соревнования** `contests/` | `contest.py` | Соревнование: даты, регистрация, статус, верификация, баллы за места |
| | `contest_age_group.py` | Допущенные возрастные группы |
| | `contest_academic_group.py` | Допущенные академические группы |
| | `contest_photo.py` | Фото соревнования |
| **Участие и итоги** `participation/` | `contest_application.py` | Заявка: личная или командная, кто подал, решение |
| | `contest_application_member.py` | Участник заявки: подтверждение, капитан, группы на дату старта |
| | `contest_result.py` | Место участника и баллы в рейтинг |
| | `document.py` | Выпущенный документ: диплом, сертификат, справка, номер и подпись |
| **Сборные** `squads/` | `squad.py` | Сборная по приказу: дисциплина, группа, размеры, файл приказа |
| | `squad_member.py` | Член сборной: место в составе, резерв, баллы |
| **Судьи и разряды** `qualifications/` | `judge_assignment.py` | Судья в коллегии соревнования и его должность; снятый судья остаётся с отметкой |
| | `qualification.py` | Разряд или судейская категория: заявка, решение, срок действия |
| | `deadline_notice.py` | Уже отправленное напоминание о сроке, чтобы не слать повторно |
| | `judge_document.py` | Документ судьи к протоколу: записка, акт, протокол |
| **Контент** `content/` | `calendar_event.py` | Событие календаря федерации: лекция, сборы, вебинар |
| | `news_article.py` | Новость: блоки текста, обложка, хэштеги, статус |
| **Уведомления** `notifications/` | `notification.py` | Уведомление в кабинете и статус письма |
| | `notification_setting.py` | Отключённые каналы по группам уведомлений |
| | `outbox.py` | Очередь отправки писем и сообщений в Telegram |
| | `telegram_link.py` | Привязка Telegram к аккаунту |
| | `bot_admin.py` | Администратор Telegram-бота и его уровень |

Новая модель — файл в папке своей группы, импорт в `backend/main.py`, строка в этой таблице и в порядке `.vscode/settings.json`.
