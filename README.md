# Платформа ФСП Оренбургской области

Сайт и кабинеты регионального отделения Федерации спортивного программирования: соревнования, запись на них, события федерации, новости и справочники. Кейс хакатона OrenCode.

## Что работает

**Без входа**
- Каталог соревнований с фильтрами и карточка соревнования: положение, фото, призовой фонд, список одобренных участников.
- Общий календарь: соревнования и события федерации (лекции, сборы, вебинары).
- Новости: лента с поиском и хэштегами, страница статьи. Три свежие статьи на главной.

**Регистрация и роли**
- Регистрация, вход, восстановление пароля, cookie-сессия с CSRF.
- Роли: спортсмен, тренер, судья, организатор, сотрудник федерации. Тренер, судья, организатор и федерация подтверждаются федерацией.

**Кабинет федерации**
- Модерация аккаунтов и ролей.
- Справочники: дисциплины, муниципалитеты, возрастные и академические группы, разряды, категории судей и другие. Создание, правка, архив.
- Все соревнования региона: создание, публикация, верификация с баллами за места.
- Модерация заявок участников: одобрить, отклонить с причиной, вернуть на рассмотрение, массово.
- События ФСП для календаря.
- Новости: редактор статьи из блоков (заголовок, текст, изображение, файл, ссылка), обложка, хэштеги, черновик, публикация, архив.

**Кабинет организатора**
- Свои соревнования: от черновика до архива, регистрация, положение и фото.
- Заявки на свои соревнования.

**Кабинет спортсмена и тренера**
- Запись на соревнование: личная заявка или команда с приглашениями и подтверждением.
- Тренер записывает подопечных, в том числе пачкой.
- Проверки на сервере: окно регистрации, возраст и академическая группа, дубли, размер команды.

**Судьи, категории и разряды**
- Судья подаёт заявку на категорию с документом, спортсмен или тренер — на разряд. Федерация присваивает или отказывает с причиной.
- Срок считается по справочнику: юношеский разряд — не дольше 18 лет, звания — бессрочно. Повышение — новая заявка на ступень выше.
- Судейская коллегия соревнования: организатор или федерация назначает судей на должности. Назначить можно только судью с категорией, действующей на дату соревнования.
- Напоминания о сроке за 30, 7 и 1 день и в день истечения, без повторов.

**Уведомления и журнал**
- Уведомления в кабинете о решениях по ролям, заявкам и верификации, приглашениях в команды и отмене соревнований. Важные решения дублируются письмом.
- Письма уходят из очереди в PostgreSQL с повторами; локально их принимает Mailpit: http://localhost:8025.
- Журнал действий для федерации: фильтры по автору, действию, объекту и периоду, изменения полей «было / стало».

**Почта и Telegram**
- Восстановление пароля кодом из письма: почта → код → новый пароль.
- Подтверждение почты кодом после регистрации, смена почты с кодом на новый адрес.
- Письма безопасности: пароль изменён, вход с нового устройства, почта изменена.
- «Настройки» в кабинете: какие события присылать на почту и в Telegram, проверка доставки одной кнопкой.
- Telegram-бот [@FSP_Oren_bot](https://t.me/FSP_Oren_bot): привязка по кнопке, уведомления с «Прочитано», мои заявки с подтверждением участия, ближайшие соревнования, настройки. «Панель федерации» с правами модератора, администратора и владельца: очередь ролей, решения кнопками, статистика, рассылка.

## Технологический стек

| Часть | Технологии |
|---|---|
| Бэкенд | Python 3.12, FastAPI 0.115, Pydantic 2, SQLAlchemy 2.0 (async) + asyncpg, Uvicorn |
| База и кэш | PostgreSQL, Redis (сессии, лимиты входа, токены сброса пароля, счётчики просмотров) |
| Файлы | SeaweedFS по S3 API, клиент `minio`; публичный и приватный бакеты, подписанные ссылки |
| Безопасность | Argon2 для паролей, cookie-сессия `sid`, CSRF-токен в заголовке `X-CSRF-Token` |
| Фронтенд | React 19, TypeScript 6 (strict), Vite 8, Tailwind CSS 4, React Router 7, TanStack Query 5, clsx |
| Качество | Pyright (0 ошибок), ESLint, Prettier, `tsc -b` |
| Запуск | Docker: один образ с PostgreSQL, Redis, SeaweedFS и API |

UI-библиотек нет: компоненты свои (`frontend/src/shared/ui`), две темы, оформление по брендбуку ФСП.

## Архитектура

**Бэкенд** (`backend/`) разбит на области, их список и назначение — в [backend/README.md](backend/README.md). Внутри области слои идут строго сверху вниз:

```
features/      роутер + схемы на каждую фичу
domain/        логика, транзакции, аудит
repositories/  SQL, Redis, S3 (pg_ / red_ / s3_)
```

ORM-модели лежат в `infrastructure/`, по одной таблице на файл. Правила — [docs/000_conventions.md](docs/000_conventions.md).

**Фронтенд** (`frontend/`) построен по Feature-Sliced Design: `app → pages → widgets → features → entities → shared`, импорт только вниз, ESLint это проверяет. Правила — [frontend/RULES.md](frontend/RULES.md).

## Запуск

Нужны Docker, Node.js 20+ и npm.

1. Бэкенд. При каждом старте схема создаётся заново и заливается демо-база из [manage/seed/seed.sql](manage/seed/seed.sql) с аватарами, положениями, приказами и согласиями из `manage/seed/`:

   ```bash
   docker build -f manage/Dockerfile -t fsp .
   docker run -d --name fsp -p 8000:8000 -p 9000:9000 -p 127.0.0.1:8025:8025 fsp
   ```

   То же через меню: `python manage/fsp.py`. Порт 9000 — хранилище файлов, без него картинки не откроются. Порт 8025 — Mailpit, там видны все письма. Swagger: http://localhost:8000/docs.

2. Фронтенд:

   ```bash
   cd frontend
   npm install
   npm run dev
   ```

   Сайт: http://localhost:5173 (запросы `/api` проксируются на `localhost:8000`).

3. Telegram-бот. Токен от @BotFather задаётся только переменной окружения, в репозиторий не кладётся:

   ```bash
   docker run -d --name fsp -p 8000:8000 -p 9000:9000 -p 127.0.0.1:8025:8025 -e FSP_TELEGRAM_BOT_TOKEN=<токен> fsp
   ```

   `python manage/fsp.py` сам передаёт `FSP_TELEGRAM_BOT_TOKEN` из окружения. Без токена всё работает, в «Настройках» видно, что бот не подключён.

### Настоящая почта (SMTP)

По умолчанию письма уходят в Mailpit. Чтобы слать на реальные адреса, перед `python manage/fsp.py` задайте переменные окружения. Пример для Яндекса с паролем приложения:

```bash
export FSP_SMTP_HOST=smtp.yandex.ru FSP_SMTP_PORT=465 FSP_SMTP_TLS_MODE=ssl
export FSP_SMTP_USERNAME=box@yandex.ru FSP_SMTP_PASSWORD=<пароль приложения>
export FSP_SMTP_SENDER="ФСП Оренбург <box@yandex.ru>"
```

Адрес отправителя должен совпадать с логином, иначе Яндекс отклонит письмо. Пароль в репозиторий и `.env` не кладём.

### Как проверить почту и Telegram

1. «Забыли пароль?» на входе → `coach@example.test` → код из Mailpit (http://localhost:8025) → новый пароль → вход.
2. Зарегистрируйтесь с новой почтой: в кабинете плашка «Подтвердите почту», код — в Mailpit.
3. Кабинет → «Настройки»: «Изменить почту» (код на новый адрес, предупреждение на старый), переключатели каналов, «Отправить тестовое».
4. «Привязать Telegram» → «Открыть Telegram» → «Запустить» в боте. Страница сама покажет привязку; дальше «Отправить тестовое» приходит и в бота.
5. В боте: меню внизу, «Мои заявки», «Соревнования», «Настройки». Под `federation@example.test` (владелец) — «Панель федерации»: очередь ролей с кнопками, статистика, рассылка.
6. Федерация → «Настройки» → «Администраторы бота»: назначить, сменить уровень, снять.
7. Войдите тем же аккаунтом из другого браузера — придёт «Вход с нового устройства».

### Как проверить судей и разряды

1. `judge@example.test` → «Моя категория»: срок истекает через 5 дней, в уведомлениях напоминание. «Повысить категорию» → первая категория, любой PDF.
2. `federation@example.test` → «Разряды и категории»: заявка в очереди. «Присвоить» показывает срок, «Отказать» просит причину.
3. `athlete@example.test` → «Мой разряд»: второй разряд и заявка на первый в очереди. `coach@example.test` → «Разряды спортсменов» → «Подать за спортсмена».
4. `organizer@example.test` → «Соревнования» → «Судьи» на карточке: назначить судью, сменить должность, снять. `judge@example.test` → «Мои назначения».

### Как проверить документы судей и отчёт

1. Страница «Чемпионата Оренбургской области по алгоритмическому программированию» → «Документы судейской коллегии»: файлы главного судьи и снятого секретаря с пометкой «снят». Под `judge@example.test` — «Добавить документ», «Заменить», «Удалить».
2. `organizer@example.test` → «Соревнования» → документы чемпионата → «Благодарности судьям»: галочки по коллегии. Протокол xlsx содержит блок документов коллегии.
3. Страница человека `judge@example.test` → вкладка «Судья»: где судил и в какой должности.
4. `athlete@example.test` → «Мои документы» → «Отчёт»: период, PDF или xlsx. Федерация скачивает отчёт со страницы любого человека, тренер — со страницы своего спортсмена.
