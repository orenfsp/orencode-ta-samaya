**Метод.** Статус ставится так:
- **✅** — цепочка «экран → эндпоинт → домен → хранилище» есть и проверена тестом;
- **⚠️** — работает с оговоркой, она указана;
- **❌** — в коде нет: поиск по сущности и синонимам пустой.

Индекс соответствия — средневзвешенный по весам критериев: ✅ = 1, ⚠️ = 0,5, ❌ = 0. Презентационные пункты П1 и П2 оцениваются на защите и в индекс не входят.

## 3. Детальный разбор проблемных зон (Discrepancy Deep Dive)

### С3 Проверка дисциплины при заявке
- **Что требует ТЗ:** «платформа проверяет возраст и дисциплину» (С3).
- **Фактическое состояние в коде:** `backend/applications/domain/eligibility.py:34-56` проверяет роль, возраст по возрастным группам на дату старта, согласие представителя и академическую группу. Дисциплины спортивного профиля в проверке не участвуют: поиск `discipline` в `eligibility.py` пуст.
- **В чём расхождение:** спортсмен может подать заявку на соревнование дисциплины, которой нет в его профиле. Тренерская заявка не сверяет связь по дисциплине (`backend/applications/domain/applications.py:143-145` проверяет только роль).
- **Влияние на систему:** нарушение бизнес-правила, без угрозы данным. Защита — подтверждение участия самим спортсменом.
- **Рекомендация по закрытию:** в `Applications.create` загрузить открытые периоды `athlete_disciplines` участников. При пустом пересечении с `contest.discipline_id` добавить проблему «дисциплина не указана в профиле». Для `as_ == COACH` требовать активную `coach_links` по `contest.discipline_id`.

### Д6 Показатели развития региона
- **Что требует ТЗ:** сводная страница показателей с источниками.
- **Фактическое состояние в коде:** показатели есть только в кабинете федерации (`backend/analytics/domain/analytics.py:172`, численность — `backend/registry/domain/registry.py:200`, источники — поле `sources`). Публичного эндпоинта показателей нет.
- **Влияние на систему:** частичный балл по Д6.
- **Рекомендация по закрытию:** публичный `GET /indicators` по готовым агрегатам (численность, соревнования года по уровням и планам) и страница с датой обновления.

### Д8 Премии Губернатора
- **Фактическое состояние в коде:** только срок ходатайств 1 февраля (`backend/deadlines/domain/deadlines.py:48`). Отбора претендентов и сумм нет.
- **Рекомендация по закрытию:** справочник правил премирования по году, отбор кандидатов из протоколов, статусы «подготовлено → направлено → назначено».

### Д11 Навигатор для новичка
- **Фактическое состояние в коде:** навигатор по кабинету (`frontend/src/widgets/cabinet-shell/ui/onboarding-tour.tsx`) и справочник понятий. Публичного раздела «где заниматься» нет, хотя `GET /organizations` и учебные группы уже есть.
- **Рекомендация по закрытию:** публичная страница: организации и группы по муниципалитету и дисциплине плюс ближайшие соревнования.

### Д1, Д2, Д9 Отсутствующие модули
- **Д1:** поиск `openid|oauth|pkce|well-known` пуст; совпадения `authorize` — только `unauthorized`.

- **Влияние:** необязательные пункты: Д1 и Д2 по 5 баллов веса, Д9 — 2.
- **Рекомендация по закрытию:** Д9 — роль `ministry` с доступом только на чтение к отчётам, календарю и сборной.

### БЕЗ-02, БЕЗ-08 Демо-секреты
- **Фактическое состояние в коде:** `backend/core/config.py:15` — `cookie_secure: bool = False`; `backend/core/config.py:45` — `SecretStr("dev-document-secret-change-me")`.
