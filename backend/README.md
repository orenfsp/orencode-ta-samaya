# Бэкенд

FastAPI-приложение одним процессом: API, фоновые задачи (очередь писем и Telegram, напоминания о сроках, синхронизация Codeforces) и Telegram-бот запускаются в `main.py`. Модели базы — в `infrastructure/`, запуск в Docker и демо-база — в `manage/`. Правила кода — `docs/000_conventions.md`.

Код разбит на области. Внутри каждой слои идут строго сверху вниз, импорт только вниз:

```
features/        фича = папка с router.py (эндпоинты) и schemas.py (тела запросов и ответов); схемы между фичами не шарятся
domain/          логика области: проверки, транзакции, аудит, уведомления
repositories/    хранилища данных; приставка — где данные: pg_ (Postgres), red_ (Redis), s3_ (файлы)
clients/         внешние сервисы: почта, Telegram Bot API, Codeforces API (есть только там, где нужны)
dependencies.py  сборка сервисов области для FastAPI Depends
```

Области сгруппированы по смыслу так же, как модели в `infrastructure/`. В проводнике VS Code они идут в этом порядке (`.vscode/settings.json`), `main.py` и `requirements.txt` — в самом конце.

| Группа | Область | Что делает |
|---|---|---|
| **Основа** | `core` | Конфиг, подключения к Postgres и Redis, единый формат ошибок, IP клиента, проверка здоровья |
| **Аккаунт** | `auth` | Регистрация, вход и выход, сессии, роли и их подтверждение федерацией, почта, восстановление пароля |
| | `people` | Страница человека, лента выступлений, привязка и синхронизация Codeforces |
| | `consents` | Согласия законных представителей и их проверка федерацией |
| **Общие службы** | `audit` | Журнал действий и его просмотр федерацией |
| | `files` | Загрузка файлов с проверкой типа, выдача по постоянной или подписанной ссылке |
| **Справочники** | `dictionaries` | Чтение справочников и управление ими: добавление, правка, архив |
| **Соревнования** | `contests` | Каталог соревнований, кабинеты организатора и федерации, жизненный цикл, верификация с баллами |
| | `events` | События федерации и общая лента календаря: события вместе с соревнованиями |
| **Участие и итоги** | `applications` | Заявки: личные и командные, приглашения, подача тренером, модерация |
| | `results` | Места участников и протокол в xlsx |
| | `documents` | Дипломы, сертификаты, благодарности, справки: выпуск, PDF, проверка по QR |
| | `ratings` | Рейтинг спортсменов по дисциплинам и группам за 365 дней |
| | `squads` | Сборные по приказу: состав из рейтинга, метки на странице человека |
| **Судьи и разряды** | `qualifications` | Разряды и судейские категории, судейские коллегии и документы судей к протоколу, напоминания о сроках |
| **Контент** | `news` | Новости: лента, теги, редактор статей |
| **Уведомления** | `notifications` | Уведомления в кабинете, настройки каналов, очередь писем и Telegram, Telegram-бот |
| **Аналитика и отчёты** | `analytics` | Дашборд федерации и выгрузка в xlsx |
| | `reports` | Отчёт по человеку в PDF и xlsx: выступления, подопечные, судейство, разряды, документы, сборные |
| | `main.py` | Приложение: модели, роутеры всех областей, фоновые задачи |
| | `requirements.txt` | Зависимости Python |

Новая область — папка со слоями выше, строка в этой таблице, роутер в `main.py` и место в порядке `.vscode/settings.json`.
